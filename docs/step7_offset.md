# 7단계 — 9점 vs 89점 계측기 offset 검증: 좌표계가 180° 다르다

> 담당 B · 2026-08-09 · 스크립트 `src/analysis_offset.py`
> 산출물 `figures/offset_calibration.png`,
> `data/processed/offset_{frame_test,rotation_scan,by_column,by_coord,structure}.csv`

## 1. 이 단계가 답하는 질문

CLAUDE.md 에는 프로젝트 시작 시점부터 **"9점과 89점은 측정 장비가 달라 약 1.5 µm
계통 offset 존재. 혼용 금지"** 라는 규칙이 적혀 있었다. 1~6단계는 이 규칙을 지켜
두 파일을 한 번도 섞지 않았다. 7단계는 그 규칙 자체를 검증한다.

| # | 질문 | 왜 중요한가 |
|---|---|---|
| Q1 | offset 은 정말 상수 1.5 µm 인가? | 상수가 아니면 단순 가산 보정으로는 못 합친다 |
| Q2 | 그 차이는 정말 *계측기* 차이인가? | 계산 공식 차이나 좌표 라벨링 차이일 수도 있다 |
| Q3 | offset 에 반경·순번·승법 성분이 있는가? | 보정식의 형태(상수 vs 선형)를 결정한다 |
| Q4 | 이 발견이 1~6단계 결론을 뒤집는가? | 뒤집힌다면 재계산, 아니면 caveat 만 |

### 답 요약

- **Q1 → 아니다. 애초에 offset 이 아니었다.** 좌표별로 재면 −1.42 ~ +3.97 µm
  (스프레드 **5.39 µm**) 로 요동친다. 원인은 **두 파일의 좌표계가 정확히 180° 회전
  관계**라는 것. 프레임을 맞추면 스프레드가 5.39 → **0.32 µm** 로 줄어든다.
- **Q2 → 절반만 계측기 차이다.** 두 파일이 `si_etch` 를 **서로 다른 공식**으로
  계산한다. 공표 offset **+1.3382 µm = 계측기 차이 +1.0617 + 공식 인공물 +0.2766**.
- **Q3 → raw 계측량 기준으로는 상수로 충분하다.** `stepheight` offset
  **+1.0617 ± 0.0471 µm**, 반경 설명력 R² = 0.026 (사실상 없음). 승법 성분
  (Deming 기울기 1.022) 을 허용해도 잔차 sd 가 0.0471 → 0.0416 (12%) 만 준다.
- **Q4 → 뒤집히지 않는다.** 9점 좌표집합이 180° 회전에 **닫혀 있고**(검증 완료)
  링/반경 통계는 회전 불변이라 4/5/6단계 수치는 **전부 그대로**다. 바뀌는 것은
  5단계 tilt 의 **방향 부호 하나뿐**이며, 이것도 물리적 방향을 정하려면 챔버
  기하 정보가 필요해 A 에게 넘긴다.

**CLAUDE.md 규칙 정정**: "약 1.5 µm" → **1.338 (공표 si_etch) / 1.062 (raw
stepheight)**. "혼용 금지" → **"프레임·공식 보정 없이 혼용 금지"** (팀 합의 필요).

## 2. 이론 배경

### 2.1 대응쌍(paired) 설계 — 왜 웨이퍼 평균끼리 비교하면 안 되는가

두 계측기의 차이를 보려고 "9점 파일의 전체 평균 40.24 vs 89점 파일의 전체 평균
41.57" 을 빼면 안 된다. 두 파일의 **웨이퍼 구성이 다르고**(9점에만 있는 웨이퍼 2장,
89점에만 있는 15장) **좌표 구성도 다르기** 때문이다. 3~5단계에서 확인했듯
웨이퍼 간 변동(drift −0.119 µm/장)과 웨이퍼 내 공간 변동(보울형, 중심 대비 +19%)이
모두 크므로, 구성 차이가 곧바로 가짜 offset 으로 새어 들어온다.

대신 **같은 lot·같은 웨이퍼 순번·같은 (X, Y)** 를 두 장비가 잰 쌍만 남긴다.

```
(lot_number, wafer_number, X, Y) 로 inner join
→ 공통 웨이퍼 73장 × 공통 좌표 9개 = 대응쌍 657개
```

쌍 안에서는 lot 효과·순번 drift·공간 패턴이 **전부 상쇄**되고 장비 차이만 남는다.
이것이 계측 시스템 비교(gauge study)의 표준 설계다.

### 2.2 좌표계 불일치는 offset 으로 위장한다

두 파일의 (X, Y) 라벨이 서로 다른 좌표계라면, 조인은 **엉뚱한 물리적 위치끼리**
짝지운다. 예를 들어 89점 파일의 (+76, 0) 이 물리적으로는 9점 파일의 (−76, 0) 과
같은 자리라면, 조인 결과의 차이값에는 계측기 차이가 아니라 **웨이퍼 위 두 지점의
식각량 차이**가 들어간다.

이때 결정적 단서는 이것이다.

> 진짜 단일 계측기 offset 이라면, **좌표 9개에서 잰 offset 이 서로 같아야 한다.**

좌표별 offset 이 −1.42 ~ +3.97 µm 로 흩어졌다는 것은 "offset 이 위치의존적이다"
라는 뜻이고, 그 위치의존성의 형태가 웨이퍼의 공간 패턴을 닮았다면 원인은
**좌표계 어긋남**이다. 그래서 판별 기준은 **좌표별 offset 의 스프레드를 최소화하는
좌표 변환을 찾는 것**이 된다.

### 2.3 이산 프레임 검정과 연속 회전 스캔 — 두 단계로 확인하는 이유

**1단계(이산)**: 반사·90° 배수 회전·전치 등 계측 장비 셋업에서 흔한 7가지 변환을
전부 시도해 좌표별 offset sd 를 비교한다. 장점은 명확하지만, **후보 7개 안에
정답이 없을 가능성**을 배제하지 못한다. 예컨대 실제가 178° 라면 180° 가 "그중
가장 나은" 답으로 뽑히지만 정답은 아니다.

**2단계(연속)**: 89점 파일의 **면 전체(89좌표)** 를 웨이퍼 평균으로 만들고
`griddata(method="linear")` 로 보간한 뒤, 질의점(9점 좌표)을 φ 만큼 회전시켜가며
0°부터 359°까지 2° 간격으로 훑는다. 최소 부근 ±10° 는 0.25° 로 재스캔한다.
연속 곡선의 최소가 어디에 오는지, **유일한 최소인지**를 본다. 89점 grid 는 15개
반경 링을 갖고 있어 보간면이 충분히 조밀하므로 이 검정이 가능하다.

### 2.4 왜 F 통계량은 판별자로 쓰지 않는가

"좌표별 offset 이 서로 같은가"는 형식상 일원배치 분산분석의 F 검정이다. 그런데
이 데이터에서는 **F 가 프레임 순위를 뒤집는다**. Y 부호 반전이 F = 93.5 로
180° 회전의 F = 100.3 보다 낮게(=더 좋아 보이게) 나오는데, sd 는 반대로 0.1887 vs
0.1091 로 180° 가 훨씬 낫다.

이유는 F 의 **분모**에 있다. F = (좌표 간 분산) / (좌표 내 분산) 인데, 틀린
프레임에서는 서로 다른 물리적 위치를 짝지운 탓에 **좌표 내 분산도 함께 부푼다.**
분자와 분모가 같이 커지면 비율은 상쇄되어 버린다. F 는 "군내 변동이 올바르게
추정됐다"는 가정 위에서만 의미가 있는데, 여기서는 그 가정 자체가 프레임에 따라
깨진다. 그래서 **판별은 sd 와 좌표 스프레드(절대 척도)** 로 하고, F 는 참고로만
싣는다.

### 2.5 preox_thickness 는 대조군이다

`preox_thickness` 는 **식각 전** 산화막 두께다. 식각 공정이 손대지 않은 양이므로
두 장비가 같은 웨이퍼의 같은 자리를 재면 **차이가 0 이어야 한다.** 이 항목이 0 이
아니면 웨이퍼 매칭 자체가 틀렸다는 뜻이고, 0 이면 매칭이 옳다는 강한 증거다.
즉 preox 는 실험의 **음성 대조군(negative control)** 역할을 한다.

이 대조군이 통과한 뒤에야 "postox 이후에서만 차이가 난다 → 차이는 식각 후 계측
단계에서 발생한다"는 추론이 성립한다.

### 2.6 Deming 회귀 — OLS 가 편향되는 이유와 λ 를 못 정하는 이유

"89점 값 = a + b × 9점 값" 의 기울기 b 를 알고 싶다. 그런데 **x(9점 값) 에도 측정
오차가 있다.** OLS 는 x 가 오차 없다고 가정하므로 기울기가 1 쪽으로 끌려간다
(regression dilution / 회귀 희석).

Deming 회귀는 양쪽 오차를 인정하고 다음을 푼다 (λ = σ²_y오차 / σ²_x오차):

```
b = [ (s_yy − λ·s_xx) + √( (s_yy − λ·s_xx)² + 4λ·s_xy² ) ] / (2·s_xy)
```

문제는 **λ 를 데이터에서 정할 수 없다**는 것이다. 대응쌍 차이의 분산은
σ²_x오차 + σ²_y오차 **합만** 알려주고, 둘을 나누려면 각 장비를 같은 자리에서
반복 측정한 데이터가 필요한데 이 데이터셋에는 없다. 그래서 λ 를 **감도분석
파라미터**로 두고 λ = 0.25 / 1 / 4 세 값에서 기울기를 병기한다. 세 값의 차이가
작으면 "λ 를 모른다는 사실이 결론에 영향이 없다"고 말할 수 있다.

관찰된 오차분산 합: si_etch 0.01191 µm² (√ = 0.1091), stepheight 0.00222 µm²
(√ = 0.0471). 만약 두 장비 오차가 같다면 각각 σ ≈ 0.077 / 0.033 µm 다.

### 2.7 Bland-Altman

두 방법의 일치도를 볼 때 산점도 + 상관계수는 오해를 부른다. 상관은 높아도 계통
offset 이 클 수 있기 때문이다. Bland-Altman 은 **x 축 = 두 방법의 평균,
y 축 = 두 방법의 차이** 로 그리고 평균 차이(bias) 와 mean ± 1.96 sd
(limits of agreement) 를 표시한다. 차이가 측정값 크기에 따라 커지면(깔때기 모양)
승법 성분이 있다는 뜻이다.

## 3. 방법과 설계 결정

사용자가 "적합한 방법을 선택하고 이유를 문서에 설명하라"고 판단을 위임했다.
네 가지 갈림길에서 아래와 같이 정했다.

### D1. si_etch 공식은 통일하지 않는다 — 발견 보고 + 분해만 한다

**발견한 것**: 두 파일이 같은 이름의 컬럼을 다른 공식으로 만든다.

| 파일 | 성립하는 항등식 | max\|err\| |
|---|---|---|
| 9점 | `si_etch = stepheight − oxide_etch` | 7.1e−15 |
| 89점 | `si_etch = stepheight − postox_thickness` | 5.0e−09 |
| 양쪽 공통 | `oxide_etch = preox − postox` | ≤ 1.0e−09 |

기하학적으로는 **89점 쪽이 맞다.** 단차(stepheight)는 남아 있는 산화막 표면에서
파인 Si 바닥까지의 높이이므로 `stepheight = postox + Si식각깊이` 이고, 따라서
`Si식각깊이 = stepheight − postox` 다. 9점 파일은 postox 대신 oxide_etch
(= preox − postox) 를 빼고 있다.

**선택지**: (ㄱ) 모든 단계를 통일된 공식으로 재계산 / (ㄴ) 현행 유지 + 분해 보고.

**(ㄴ)를 고른 이유 세 가지.**

1. **결론이 안 바뀐다.** 공식 통일은 한 파일 안의 모든 행에 거의 상수(+0.28 µm)를
   더하는 일이다. 3~6단계의 결론은 전부 *변동*에 관한 것 —— 산포 3분해의 비율,
   drift 기울기, 관리도 σ, Cp/Cpk 의 공차 비율. 모든 행에 상수를 더해도 이들은
   변하지 않는다. 실제로 **한 파일 안에서는 정의가 완전히 일관**(잔차 1e−9)하고,
   1~6단계는 두 파일을 **한 번도 섞지 않았다.** 인공물은 순수하게 *파일 간* 문제다.
2. **재현성이 깨진다.** `si_etch` 는 Zenodo 공개 데이터의 게시자 컬럼이다. 이것을
   조용히 다시 계산해 쓰면 우리 산출물이 원본과 대조 불가능해지고, A 의 모델
   테이블과도 어긋난다. 원본 컬럼은 원본대로 두고 차이를 **문서화**하는 편이
   협업과 재현 양쪽에 낫다.
3. **비용 대비 효용.** 통일하면 1~6단계 6개 단계를 전부 재검증해야 하는데,
   위 1번에 의해 얻는 것이 없다.

다만 **이 발견은 반드시 기록되어야 한다.** 누군가 두 grid 를 실제로 합치는
순간, 이 +0.28 µm 는 진짜 오차가 되기 때문이다. 그래서 대신 **분해**를 산출물로
남긴다 (4.3절).

### D2. 5단계는 재계산하지 않고 좌표계 caveat 를 달고 A 에게 확인을 요청한다

180° 발견이 위협하는 것은 5단계의 **방위각 tilt 방향 θ₀ = −93.8°** 하나다.

**먼저 무엇이 안 바뀌는지 검증했다.**

- 9점 좌표 9개 집합이 **180° 회전에 닫혀 있는가 → True.**
  (0,0) 은 자기 자신, (±38,±38) 4개는 서로 맞바꿔지고, (±76,0)·(0,±76) 4개도
  그렇다. 즉 4단계의 "9점 좌표 부분집합" 계산은 **같은 9개 점의 집합**을 그대로
  쓰므로 결과가 완전히 동일하다.
- 반경 `r = √(X²+Y²)` 는 180° 회전에 불변 → 5단계의 링 통계, 반경 프로파일,
  링별 drift 기울기, 6단계의 비균일도·σ·Cp 전부 불변.

**바뀔 수 있는 것은 tilt 방향 부호뿐인데, 이것을 우리가 정할 수 없다.** 어느 파일의
프레임이 물리적 챔버 좌표인지는 계측 CSV 만으로는 알 수 없다. 답은 챔버 기하
(가스 인젝터 / 펌프 포트 / RF 급전 방향) 나 `.nc` 메타데이터에 있고 그쪽은 A 의
영역이다. **근거 없이 −93.8° 를 +86.2° 로 고쳐 쓰는 것은 caveat 를 다는 것보다
나쁘다** —— 틀릴 확률이 정확히 50% 인 숫자를 확정된 것처럼 보이게 만들기 때문이다.

**그리고 이 발견은 5단계를 약화시키는 게 아니라 강화한다.** 두 파일에서 r = 76 mm
링의 tilt 를 **독립적으로** 계산했다 (4.6절): 진폭 1.303 vs 1.406 µm (비 1.079),
방향 +87.3° vs −93.9° (차이 **181.2°**). 서로 다른 장비 두 대가, 서로 180° 돌아간
좌표계에서, **같은 크기의 비대칭을 정확히 반대 방향에서** 봤다. 프레임을 맞추면
일치한다. 즉 5단계 tilt 는 한 계측기의 아티팩트가 아니라 **물리적 실재**다.

### D3. offset 은 3종 병기하되 실무 권고는 stepheight 상수로 한다

**3종 병기 이유**: 숫자 하나만 내면 그 안의 21% 가 공식 인공물이라는 사실이
숨는다. "1.34" 만 보고 그걸 `stepheight` 에 적용하면 0.28 µm 를 **과보정**한다.
어떤 양에 붙는 offset 인지를 반드시 함께 명시해야 한다.

| 기준량 | offset | sd | 좌표 스프레드 |
|---|---|---|---|
| si_etch (공표, 공식 불일치 포함) | **+1.3382** | 0.1091 | 0.318 |
| si_etch (둘 다 9점 공식) | +1.0205 | 0.0907 | 0.209 |
| si_etch (둘 다 89점 공식) | +1.1027 | 0.1026 | 0.255 |
| **stepheight (raw 계측량)** | **+1.0617** | **0.0471** | **0.144** |

**stepheight 를 권고하는 이유 네 가지.**

1. **유일하게 파생량이 아니다.** 나머지는 전부 다른 컬럼의 뺄셈이라 공식 선택이
   섞여 들어간다. stepheight 는 장비가 직접 잰 값이다.
2. **sd 가 절반 이하** (0.0471 vs 0.1091, 2.3배).
3. **좌표 스프레드가 절반 이하** (0.144 vs 0.318) — 즉 좌표 무관 상수에 가장 가깝다.
4. **반경 의존이 사실상 사라진다** (R² 0.236 → 0.026). si_etch 에 남아 있던
   반경 구조 대부분이 공식 인공물이었다는 뜻이다.

**상수로 권고하고 기울기로 하지 않는 이유**: 승법 성분을 허용하면
(Deming 기울기 1.0224) 잔차 sd 가 0.0471 → **0.0416** 으로 12% 줄 뿐이다.
관측된 stepheight 범위 39~44 µm 에서 2.2% 기울기는 약 0.11 µm 폭인데, 이는
쌍차이 sd 의 2.3배에 불과하다. 게다가 승법 성분을 상수와 깨끗이 분리하려면
독립 표준물이 필요한데 없다. **얻는 것이 작고 가정이 늘어나므로 상수를 쓴다.**
기울기는 "남은 구조"로 보고만 한다.

### D4. 그림은 1장(3패널)으로 한다 — 계획의 2패널에 (b) 를 추가

브리핑 때는 (a) 좌표별 offset + (c) Bland-Altman 2패널이었다. **(b) 연속 회전각
스캔을 추가**했다.

- 180° 는 이 단계에서 가장 놀랍고 가장 결정적인 발견인데, 표의 한 줄
  ("180.00°에서 sd 0.0408") 로는 **그 최소가 얼마나 날카롭고 유일한지**가
  전달되지 않는다.
- 곡선을 그리면 **다른 국소 최소가 없다**는 것이 한눈에 보인다. 이산 7개 후보를
  넘어 연속적으로 배제했다는 점을 그림 없이는 주장하기 어렵다.
- **별도 그림으로 분리하지 않은 이유**: 세 패널이 하나의 질문 사슬
  ("offset 이 좌표마다 다르다 → 왜 → 고치면 뭐가 남나") 을 순서대로 답하므로
  한 장에 두어야 서사가 끊기지 않는다.

**이산 프레임 검정** (si_etch 기준, 좌표별 offset 의 sd 가 작을수록 옳은 프레임):

| +90° 회전 (−Y, X) | 1.0773 | 2.963 | 8,414.6 |
| −90° 회전 (Y, −X) | 1.0900 | 3.055 | 7,152.7 |

180° 회전이 sd 를 **1.5217 → 0.1091, 14배** 줄인다.
(F 열이 순위를 뒤집는 이유는 2.4절 참조 — 판별자로 쓰지 않는다.)

**연속 회전각 스캔** (stepheight 기준, 89점 면 전체를 보간):

| φ | 0° | 90° | 175° | **180°** | 185° | 270° |
|---|---|---|---|---|---|---|
| sd (µm) | 1.5240 | 1.0777 | 0.1009 | **0.0408** | 0.1065 | 1.0922 |

**최소 = 정확히 180.00°** (0.25° 격자). 175°/185° 에서 이미 2.5배 나빠지므로
"대략 180°" 가 아니라 **정확히 180°** 다. 다른 국소 최소는 없다.

> **판정**: 두 계측 파일은 **웨이퍼를 180° 돌려 놓고 잰 것**이거나, 좌표 라벨 부호
> 규약이 반대다. 계측 장비 셋업에서 매우 흔한 종류의 불일치이며, 실제 물리적
> 웨이퍼 방향이 어느 쪽인지는 이 데이터만으로 알 수 없다.

### 4.3 offset 분해 — 1.338 µm 중 얼마가 진짜 계측기 차이인가

180° 보정 후 657 대응쌍 기준 항목별 차이:

| 항목 | 9점 평균 | 89점 평균 | offset | sd |
|---|---|---|---|---|
| **preox_thickness (대조군)** | 1.0016 | 1.0018 | **+0.0001** | 0.0036 |
| postox_thickness | 0.3831 | 0.3420 | −0.0411 | 0.0847 |
| **stepheight (raw)** | 40.855 | 41.916 | **+1.0617** | 0.0471 |
| oxide_etch | 0.6186 | 0.6598 | +0.0412 | 0.0847 |
| **si_etch (공표)** | 40.236 | 41.574 | **+1.3382** | 0.1091 |

**대조군이 통과했다.** preox offset 이 +0.0001 ± 0.0036 µm 로 **완벽히 0** 이다.
식각 전 산화막에는 장비 차이가 없다 → 웨이퍼·좌표 매칭이 옳고, 차이는 전부
**식각 후 계측 단계**에서 생긴다.

```
공표 offset  +1.3382 µm
  = 계측기 차이   +1.0617 µm   (stepheight raw, 79%)
  + 공식 인공물   +0.2766 µm   (si_etch 정의 불일치, 21%)
```

### 4.5 offset 은 상수인가

| | si_etch | stepheight |
|---|---|---|
| offset ± sd | +1.3382 ± 0.1091 | **+1.0617 ± 0.0471** |
| 반경 기울기 | −0.002309 µm/mm, p = 3.7e−40, **R² = 0.236** | +0.000328 µm/mm, p = 3.9e−05, **R² = 0.026** |
| 웨이퍼 순번 기울기 | −0.00606 µm/장, p < 1e−4 | −0.00182 µm/장, p = 0.0048 |
| OLS 기울기 | 1.0335 [1.0258, 1.0413], 잔차 sd 0.1037 | 1.0215 [1.0184, 1.0246], 잔차 sd **0.0416** |
| Deming λ = 0.25 / 1 / 4 | 1.0416 / 1.0386 / 1.0356 | 1.0228 / **1.0224** / 1.0219 |

- **반경**: stepheight 는 p 는 유의하지만 R² = 0.026 으로 실무적 의미가 없다
  (657쌍이면 미세한 기울기도 유의해진다).
- **순번**: 두 항목 모두 유의하지만 −0.0018 µm/장 × 10장 = 0.018 µm 로,
  쌍차이 sd 0.047 의 40% 수준이다. 계측기 노후가 아니라 잔여 공간 불일치의
  흔적일 가능성이 크다.
- **승법**: Deming 기울기가 λ 를 16배 바꿔도 1.0219 ~ 1.0228 로 거의 안 움직인다.
  → **λ 를 모른다는 사실이 결론에 영향을 주지 않는다.** 기울기는 존재하지만
  (약 2.2%) 상수 보정 대비 잔차 개선이 12% 뿐이라 D3 대로 상수를 쓴다.

### 4.6 1~6단계에 미치는 영향 — 그리고 5단계의 독립 검증

| 검사 | 결과 |
|---|---|
| 9점 좌표집합이 180° 회전에 닫혀 있는가 | **True** |
| → 4/5/6단계의 "9점 좌표 부분집합" 결과 | **전부 불변** |

**r = 76 mm 링 tilt 를 두 파일에서 독립 계산:**

| grid | a (cos) | b (sin) | 진폭 | 방향 |
|---|---|---|---|---|
| 9점 | +0.062 | +1.301 | 1.303 µm | **+87.3°** |

방향 차이 **181.2°**, 진폭 비 **1.079**. 서로 다른 계측기 두 대가 180° 돌아간
좌표계에서 같은 크기의 비대칭을 정확히 반대 방향에서 봤다. **5단계 tilt 는
계측 아티팩트가 아니라 물리적 실재다** — 이것이 이번 단계의 부수적 수확이다.

## 7. 한계

1. **어느 프레임이 물리적으로 옳은지 모른다.** 180° 관계는 확정했지만, 웨이퍼
   노치가 어디를 향했는지는 계측 CSV 에 없다. → A 에게 이관 (8절).
2. **λ 를 못 정한다.** 각 장비의 반복 측정이 없어 오차분산의 **합만** 식별된다
   (2.6절). 감도분석으로 우회했고 결론이 안 바뀌는 것은 확인했지만, 각 장비의
   개별 정밀도는 끝내 모른다.
3. **대응쌍이 9개 좌표뿐이다.** 89점 파일의 나머지 80좌표에는 대응하는 9점 측정이
   없다. 따라서 offset 의 반경 의존을 r ≤ 76 mm 에서만 검정했고, 5단계에서 가장
   극적이었던 **r > 80 mm edge 영역은 검증 범위 밖**이다.
4. **보간 오차.** 연속 스캔은 89점 면을 linear 보간해 만든 것이라, 89점 grid 가
   성긴 곳에서는 sd 가 약간 과대평가될 수 있다. 다만 최소가 0.25° 격자에서
   정확히 180.00° 에 떨어졌고 ±5° 에서 2.5배 악화하므로 판정에는 영향이 없다.
5. **stepheight 순번 기울기 −0.0018 µm/장 (p = 0.0048) 을 설명하지 못했다.**
   계측기 drift 인지 잔여 정렬 오차인지 구분할 근거가 없다.
6. **공식 인공물 +0.2766 µm 를 "상수"로 다뤘지만 엄밀히는 산화막 두께의 함수다.**
   대수적으로 전개하면
   `si_89 − si_9 = (step_89 − step_9) + preox_9 − postox_9 − postox_89`
   = 1.0617 + (1.0016 − 0.3831 − 0.3420) = 1.0617 + 0.2765 로 정확히 맞는다.
   즉 인공물은 preox 가 1.00 µm 로 거의 일정하고 postox 산포가 작기 때문에
   상수처럼 보이는 것이며, 산화막 두께가 다른 조건에서는 값이 달라진다.
