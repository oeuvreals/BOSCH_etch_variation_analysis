## 2026-08-08 (A: 2단계 요약 피처 생성 + 공정 드리프트 인사이트)

**목적**: 27채널 시계열을 웨이퍼당 1행으로 축약해 VM 모델 입력을 만들고,

**산출물**: `src/process_features.py` → `data/processed/process_features.parquet`
(96 웨이퍼 × 108 피처 + 키). 채널별 4종:
- `mean`(평균 수준), `std`(변동성·펄싱 진폭 반영),
- `slope`(웨이퍼 **내부** 시간 기울기 /s = 런 내부 드리프트),
- `range`(robust p95-p05 = 펄싱 스위칭 폭 프록시).
왜 4종인가: BOSCH는 펄싱 공정이라 평균만으론 스위칭 진폭·듀티를 못 잡는다.
mean(레벨)·std/range(스위칭)·slope(드리프트)로 **레벨/변동/추세**를 분리.

### 인사이트 1 — 지휘 채널 vs 응답 채널 (피처 스크리닝 근거)
- 웨이퍼 간 std≈0인 `range` 6종: **Gas4Flow/Gas5Flow(C4F8/SF6 펄스 진폭),
  EpdIntensity, Heater1Temp, SourceRF2** 등. Gas4/5는 진폭이 매 웨이퍼 동일(설정값).
- **판단**: 설정값(지휘) 채널의 진폭은 웨이퍼마다 똑같아 VM 정보량 0. 정보는
  **규제/응답 채널**(매칭 캐패시터, 반사파, 온도)의 미세 변동에 있다 → 저분산
  피처는 `model.py`에서 분산필터로 자동 제거 예정.
- **주의(방법론)**: CV(=std/|mean|)로 정보량 랭킹하면 slope처럼 평균≈0 피처가
  CV 폭발로 상위권을 오염시킨다. **0중심 피처는 절대 std로 스크리닝**해야 함.

### 인사이트 2 — 챔버 임피던스 드리프트가 유력한 식각 드리프트 원인
- **웨이퍼 진행위치(1→10)와 채널 상관, lot 교락 제거(within-date) 후**:
  - `PlatenRFTuningCapacitor__mean` **within-lot r=+0.768** (pooled +0.743과
    거의 동일 → lot/컨디셔닝 교락 아님, **진짜 웨이퍼-진행 드리프트**).
  - 보강: `Heater3/4Temp` +0.34, `HeliumBPFlow` -0.27, `PlatenDcBias` -0.25,
    `SourceRFReflectedPower` +0.17 (모두 약하지만 방향 일관).
  - **음성 결과**: `SourceRFLoadPower` within-lot r≈-0.03 → **ICP 소스 파워는
    규제되어 드리프트 없음.** 즉 식각 드리프트는 파워 감소가 아니다.
- **공정 해석**: 플래튼(바이어스) RF 매칭의 튜닝 캐패시터가 웨이퍼가 쌓일수록
  한 방향으로 이동 = 챔버 RF **임피던스가 계통적으로 드리프트**. 원인 후보는
  (a) C4F8 패시베이션 폴리머·식각 부산물의 챔버벽/전극 누적, (b) 전극·벽 온도
  상승(Heater·He backside 흐름 동반 변화). 둘 다 전형적 챔버 컨디셔닝 드리프트.
- **왜 중요**: 이 캐패시터 위치는 사실상 **내장 챔버-상태 센서**. -1.7% si_etch
  드리프트의 1순위 기전 후보이자 SPC 조기경보 지표 후보. 소스 파워가 규제됨을
  확인했으므로 기전을 "임피던스/열"로 좁힘.
- **미해결(교락 한계)**: date를 lot 프록시로 썼다. B의 `lot_conditions.csv` 도착 후
  실제 lot·컨디셔닝(C/Si/SiO2 ×1/3/9)으로 재계층화해 확정할 것.

### 인사이트 3 — EpdIntensity는 연속 피처가 아니라 first-wafer 플래그
- `EpdIntensity__mean`: 위치2~10에서 `min=max=0.123`(완전 상수), **위치1만
  ~18.5–19.4** (10개 date 전부 일관). 위치와의 상관 -0.52는 **단일점 지레**일 뿐
  단조 드리프트 아님.
- **해석**: 매 lot **첫 웨이퍼만 EPD가 살아있고** 이후는 바닥값에 고정 → 취득
  설정상 첫 장만 로깅되거나 first-wafer effect. 연속 VM 피처로 부적합.
- **판단/조치**: EpdIntensity mean/range를 그대로 쓰지 말고 `is_first_wafer`
  이진 플래그로 변환하거나 제외. B에게 EPD 취득 설정 확인 요청.
- (정정) 8/8 초기 스캔의 "EpdIntensity std≈122 살아있음"은 **위치1에 집중된
  변동**이었음. 대다수 웨이퍼에선 사실상 상수.

### 인사이트 4 — 런 내부(11분) 드리프트도 방향 100% 일관
- `slope` 부호가 전 웨이퍼 동일한 채널: `SourceRFPeakToPeak`(+0.67/s),
  `PlatenRF*Capacitor`(매칭 캐패 이동), `SourceRFReflectedPower`(-0.056/s, 반사파
  감소=플라즈마 안정화), `Gas1Flow`(+, SF6↑)·`Gas4Flow`(-, C4F8↓)=식각/패시베이션
  균형이 런 내에서 식각쪽으로 이동.
- **뉘앙스**: 방향이 전 웨이퍼 동일 = 이 slope는 웨이퍼 간 분산이 작다 →
  물리적으론 실재하나 **웨이퍼 구분(VM 예측)엔 기여 적음**. 인사이트 2의
  '웨이퍼 간' 드리프트(캐패 mean)와는 **다른 시간척도**(런 내부 vs 웨이퍼 간)이나
  같은 임피던스-드리프트 기전을 두 척도에서 함께 가리킴.

## 2026-08-08 (B: 3단계 — 산포 계층 분해)

- **함정 발견**: 측정 위치가 전 웨이퍼 동일 고정 좌표라, 통상적 nested ANOVA
  (위치를 랜덤 잔차로 취급)를 쓰면 **웨이퍼 간 성분이 0으로 붕괴**한다.
  σ_e/√9 = 1.02/3 = 0.34 ≈ 실제 웨이퍼 평균 산포 0.344 라서 전부 샘플링 노이즈로 흡수됨.
  → 위치를 **고정 인자**로 분리한 직교 제곱합 분해로 해결
  (`y = µ + lot + wafer + loc + e`, 런타임 assert 로 합 일치 확인).
- **주의**: `ols(y ~ C(lot) + C(wafer_uid) + C(loc))` 는 lot 이 wafer_uid 에 완전 중첩되어
  **rank deficient** → `anova_lm` 제곱합이 깨진다(총합이 전체 SS 초과). 인자별 단독 적합
  `.ess` 비교로 교차검증해야 함. 최종 오차 1.1e-12(9pt) / 2.3e-11(89pt).
- **결과 (측정점 전체 기준)**: 9점 전체 σ=1.022 µm — lot 0.70% / drift 7.97% /
  웨이퍼랜덤 2.67% / **웨이퍼 내 위치 88.19%** / 잔차 0.47%.
  89점 σ=3.610 µm — 0.15 / 0.76 / 0.31 / **98.25** / 0.52%.
- **결과 (웨이퍼 평균 기준)**: 9점 σ=0.344 µm — lot 6.2% / **drift 70.3%** / 랜덤 23.5%.
  89점 σ=0.400 µm — 12.2 / **62.1** / 25.6%.
- → **산포의 1순위는 웨이퍼 내 반경 프로파일, 2순위는 lot 내 순번 drift.**
  lot 간 차이는 거의 없다(=컨디셔닝 조건 효과가 작다는 첫 신호).

## 2026-08-08 (B: 4단계 — drift 정량화 + 조건 비교)

- **공통 기울기**(lot 고정효과 흡수): 9점 **−0.1056 µm/장** [−0.1191, −0.0921] p=8e−24,
  89점 **−0.1188** [−0.1339, −0.1038] p=8.5e−26.
  10장 처리 시 누적 **−0.95 ~ −1.07 µm (−2.4%)**. 독립 계측 2종이 같은 답.
- **기울기 음수인 lot = 18/18** (9점 8/8, 89점 10/10). 개별 p<0.05 는 7/8·9/10이고
  미달 lot 은 n=5, n=4 소표본뿐. lot별 R² 0.65~0.91.
- **형태 진단**: 2차항(p=0.169/0.156)·First Wafer 더미(p=0.220/0.422) 모두 기각 못 함
  → **10장 범위에서는 선형으로 충분**하고, 1번만 튀는 계단형이 아니라 연속 감소.
  포화가 없다는 증명은 아님(시상수가 10장보다 길 수 있음).
- **컨디셔닝 조건 효과 없음 (핵심 음성 결과)**:
  `cond_type` p=0.130(9점)/0.300(89점), `cond_rep` p=0.932/0.949.
  89점 재질별 평균 기울기 Chuck −0.128 / Si −0.129 / SiO2 −0.099,
  횟수별 1회 −0.125 / 3회 −0.119 / 9회 −0.116 → **9배 늘려도 7% 변화**.
  검정력 감안한 정확한 서술: **"조건은 기울기를 ±0.055 µm/장 이상 바꾸지 못한다."**
  수준(lot 평균)에 대한 효과도 전부 p>0.05. 조건은 **날짜와 완전 교락**임에 유의.
- **lot 8만 이상치**: 기울기 −0.0558 (공통의 절반, n=10, CI 좁음). 유일하게 공통 CI 밖.
  같은 SiO2_3x 인 lot 7(−0.112)·lot 10(−0.128)과 어긋나 조건으로 설명 안 됨.
  → **A에게 `Process_data.nc` 에서 lot 8 이상 패턴 확인 요청.**
- **재현성 (lot 1 vs lot 9, 동일조건 50일 간격)**: 9점 수준 차이 **+0.002 µm**,
  기울기 차이 +0.0027. 웨이퍼 평균 σ(0.344)의 0.6% → **drift 는 장비 노이즈가 아니다.**
- **선택비 부호 불일치 원인 규명** (9점 +0.179 vs 89점 −0.158):
  - IDW 보간 가설 **기각** — 157점 전부 빼도 −0.158 → −0.153 (3% 변화).
  - **89점을 9점 좌표로 제한하면 si_etch 기울기 −0.1053 vs 9점 −0.1056 → 거의 완전 일치.**
    즉 두 데이터셋의 si_etch 기울기 차이는 장비가 아니라 **좌표 집합(edge 포함 여부)** 탓.
    → **edge 에서 drift 가 더 크다** (5단계 컨투어에서 확인할 것).

### 인사이트 2 **정정** — PlatenRFTuningCapacitor는 식각 드리프트의 '원인'이 아니라 '런-내부 동반지표'
타깃 조인 후, 위치가 아니라 **실제 si_etch**와 직접 검증(교락 제거):
- **[A] within-lot** `capacitor__mean` vs `si_etch_mean`: **r=−0.650**
  (8 lot 전부 음수 −0.455~−0.843, 컨디셔닝 무관). 런 안에서 캐패↑→식각↓ 일관.
  (참고: 위치↔si_etch −0.887, 위치↔capacitor +0.847)
- **[B] 용량-반응 실패**: lot별 cap_slope vs etch_slope, 8 lot 상관 **r=+0.889(역방향)**.
  캐패 더 드리프트한 lot이 오히려 식각 덜 떨어짐(lot7 cap최대/etch최소낙폭, lot4 반대).
  caveat: lot7 n=5.
- **[C] Chuck_3x 반복쌍**(lot1 07-02 vs lot9 08-21, 7주 노화, **컨디셔닝 고정**):
  cap level **+0.083 이동**, etch level **+0.002(불변)**. slope 패턴은 재현.

  가장 강한 증거**('컨디셔닝별 민감도 차이' 변명도 차단).
- **[D]** 컨디셔닝 LEVEL 효과 미미(etch 40.08~40.32, cap 28.61~28.70).

### 모델링 함의 (4단계 설계 반영)
- within-lot(−0.65)은 성립하나 **between-lot 전이 안 됨** → **GroupKFold(lot)이 바로 이
  전이 실패를 시험**한다. 랜덤분할 시 같은 lot이 train/test로 새어 −0.65가 거짓 부풀림.
- 조치: **캐패시터를 핵심 피처로 선지정하지 말 것.** in-lot fit vs cross-lot CV
  **점수격차**를 동반지표성 진단으로 사용.
- **두 목표 분리**: 목표1(산포분해·원인) — 캐패 원인 아님, 공통 within-run 물리 탐색 필요.
  목표2(SPC 드리프트 감지) — 캐패는 **런-내부 드리프트 센서로 유효**, B 관리도 지표 후보.
- **B의 "A·B 결과 대조" 후속에 대한 답**: B가 제안한 "캐패시터 변화량 vs si_etch
  기울기 lot 단위 회귀"를 수행한 게 위 [B] 용량-반응(r=+0.889 역방향). 결론적으로
  캐패시터는 원인이 아니라 동반지표이며, 두 시간척도(런 내부 vs 웨이퍼 간)를 구분해야 함.
