## 1. 이 단계가 답하는 질문

3단계에서 산포를 lot / wafer / loc(측정 위치) 3계층으로 분해했고, 89점 기준
**loc 성분이 전체 제곱합의 98.25%(sd 등가 3.578 µm)** 라는 압도적 결과를 얻었다.
그런데 3단계는 "loc 성분이 크다"까지만 말했지 **그것이 공간적으로 어떤 모양인지**는
답하지 못했다. 크기만 알고 모양을 모르면 개선 방향을 못 잡는다.

4단계에서는 순번 drift 를 −0.1056 µm/장(9점) / −0.1189 µm/장(89점)으로 정량화하고,
두 값의 차이가 순전히 **측정 grid 차이** 때문임을 밝히면서
"89점 grid 가 더 가파른 기울기를 보는 이유는 9점이 놓치는 영역이 더 빨리 drift 하기
때문일 것"이라는 **추론**을 남겼다. 5단계는 그 추론을 공간적으로 정면 확인한다.

| 질문 | 답하는 방법 |
|---|---|
| Q1. 식각량은 웨이퍼 위에서 어떤 공간 패턴인가? | 링별 반경 프로파일 + 컨투어 |
| Q2. loc 성분 98.25% 는 무엇으로 이루어졌나? | 반경 / 방위각 / 국소 3분해 |
| Q3. drift 는 웨이퍼 위에서 균일한가? | 89개 좌표 각각에서 기울기 회귀 → drift 맵 |
| Q4. 방위각 비대칭은 장비 탓인가 웨이퍼 배치 탓인가? | lot별 tilt 벡터 + Rayleigh 검정 |
| Q5. 9점 grid 는 무엇을 얼마나 놓치는가? | 같은 89점 데이터를 9점 좌표로 잘라 대조 |

Q3 이 4단계에서 넘어온 숙제이고, Q5 가 이 단계의 **실무 메시지**다.

## 2. 이론 배경

### 2.1 왜 웨이퍼 가장자리가 더 깊게 깎이는가 (edge roll-up)

BOSCH DRIE 에서 반경 방향 불균일이 생기는 경로는 여러 개가 겹친다.

1. **시스(sheath) 곡률과 이온 입사각** — 웨이퍼 가장자리, 특히 포커스링과의 경계에서
   플라즈마 시스가 평평하지 않고 휜다. 이온은 시스 전기장에 수직으로 가속되므로
   시스가 휘면 이온 궤적이 기울고, 국소 이온 flux 와 각도 분포가 중심부와 달라진다.
2. **로딩 효과(loading)** — 가장자리는 반응종이 공급되는 입체각이 크고 확산 경계층이
   얇다. 즉 F 라디칼 공급이 중심보다 유리하다. 반대로 웨이퍼 중심은 주변 노출 면적이
   소비한 라디칼의 "그늘"에 놓인다.
3. **패시베이션 폴리머 재증착 비대칭** — C₄F₈ 스텝에서 생긴 폴리머는 배기 흐름을 따라
   이동하므로 중심부에 상대적으로 더 오래 머문다. 패시베이션이 두꺼우면 실효 식각률이
   떨어진다.
4. **척 냉각의 가장자리 약화** — 정전척의 열접촉이 가장자리에서 나빠져 국소 온도가
   올라가고, 화학 식각 성분이 온도에 지수적으로 반응한다.

이 경로들이 합쳐져 전형적으로 **중심에서 완만하게 낮아졌다가 가장자리에서 급격히
치솟는 보울(bowl)형** 프로파일을 만든다. 현장에서 이 가장자리 급등을
**edge roll-up** 이라 부르며, 보통 최외곽 5~10 mm 에서 집중적으로 나타난다.

### 2.2 왜 가장자리가 더 "빨리" drift 하는가

4단계에서 drift 의 원인을 **챔버 벽 폴리머 축적 → F 라디칼 소모(radical loading)**
로 지목했다. 이 메커니즘은 drift 가 반경에 의존할 것을 예측한다.

- drift 는 **라디칼 소스 농도의 감소**로 작용한다.
- 웨이퍼 가장자리의 식각은 **확산(공급) 지배**에 가깝고, 중심부는 상대적으로
  **반응 지배**에 가깝다. 공급 지배 영역은 소스 농도 변화에 대한 이득(gain)이 크다.
- 또한 가장자리는 폴리머가 쌓이는 **챔버 벽에 물리적으로 가깝다.**

따라서 "벽이 더러워질수록 가장자리가 먼저, 더 크게 손해를 본다"는 예측이 나오고,
이것이 곧 4단계가 남긴 추론(9점이 놓치는 영역이 더 빨리 drift)의 물리적 근거다.

### 2.3 왜 반경을 다항식이 아니라 링 고정효과로 두는가

사전 탐색에서 반경 프로파일이 **단조가 아니라 보울형**임을 확인했다. 이 사실이
모델 설계를 직접 강제한다.

- 저차 다항식(2~3차)은 최외곽의 급등을 따라가지 못해 **가장자리에서 계통 편향**을
  남긴다.
- 고차 다항식은 **Runge 현상**으로 데이터 끝단에서 진동한다. 하필 가장 중요한
  영역이 끝단이다.
- 반경을 잘못 지정하면 그 잔여 편향이 **방위각 항으로 새어 들어간다.** 5단계의
  핵심 결론 중 하나가 방위각 비대칭이므로, 이 오염은 치명적이다.

반면 이 데이터는 반경 링이 **15개뿐**이고 각 링에 좌표가 1~12개씩 있다. 그래서
링을 **범주형 고정효과 `C(ring_id)`** 로 넣으면 자유도 14 만 쓰고 **반경 구조를
함수형 가정 없이 무손실로 흡수**할 수 있다. 비모수 처리의 대가가 거의 없는 상황이라
다항식을 쓸 이유가 없다.

### 2.4 방위각 1차 조화항 (tilt)

반경을 흡수한 뒤 남은 잔차에 대해

```
value ~ C(ring_id) + cos θ + sin θ
```

를 적합한다. `cos θ`, `sin θ` 계수 (a, b) 는 웨이퍼 전체가 **한쪽으로 쏠린 성분**을
잡아낸다(1차 조화항 = tilt).

- 진폭 `A = √(a² + b²)` — 비대칭의 크기 (µm)
- 방향 `θ₀ = atan2(b, a)` — 어느 쪽이 더 많이 깎이는가

`C(ring_id)` 를 먼저 넣었기 때문에 이 항이 잡는 것은 **순수한 방위각 성분**이고,
`ΔR²` 가 그 기여도가 된다. 중심점(r=0)은 θ 가 정의되지 않으므로 `cos θ = sin θ = 0`
으로 두어 회귀에서 방위각 정보를 제공하지 않게 한다.

### 2.5 Rayleigh 검정 — 방향이 우연히 모인 것인가

lot 마다 tilt 방향 θᵢ 를 구하면 **각도 10개**가 나온다. 각도는 −180°와 +180°가
같은 점이라 산술평균·표준편차가 성립하지 않는다. 그래서 **원형 통계(circular
statistics)** 를 쓴다.

각 방향을 단위벡터로 보고 합한 뒤 길이를 평균낸 값

```
R̄ = |Σ exp(i·θᵢ)| / n
```

이 **방향 집중도**다. 방향이 완전히 흩어지면 R̄ ≈ 0, 한 방향으로 모이면 R̄ → 1.

- **H₀**: 방향이 원 위에 균일 분포 (= lot 마다 비대칭 방향이 제멋대로)
- 검정통계량 `Z = n·R̄²`, p 는 Zar 의 고차 근사식으로 계산

> ⚠️ n=10 이라 **정확 분포가 아니라 근사식**을 썼다. 다만 아래 결과의 R̄ 가 0.998 로
> 극단이라 근사 오차가 결론을 뒤집을 여지는 없다.

**이 검정이 원인을 좁혀주는 이유**: 웨이퍼는 lot 마다 새로 로딩된다.

- 비대칭이 **웨이퍼 배치·정렬 오차** 때문이라면 → 방향이 lot 마다 랜덤 → H₀ 채택
- 비대칭이 **챔버에 고정된 기하**(가스 인젝터 위치, 펌프 포트 방향, RF 급전 위치,
  척 냉각 배관) 때문이라면 → 방향이 항상 같음 → H₀ 기각

### 2.6 보간의 위험 — cubic 오버슈트

컨투어 그림은 89개 실측점을 연속 면으로 보간해 그린다. `griddata(method="cubic")`
은 CloughTocher C¹ 보간이라 부드럽지만, **기울기가 급한 구간 근처에서 원 데이터
범위를 벗어나는 값(overshoot / undershoot)을 만들 수 있다.** 이 데이터는 가장자리에서
기울기가 급하므로 정확히 위험 구간이다.

그래서 **linear 보간 면을 따로 계산해 `max|cubic − linear|` 를 상한으로 보고**하고,
컨투어 위에 실측 89점을 산점도로 겹쳐 독자가 직접 검증할 수 있게 했다.
또한 볼록껍질 밖과 최외곽 측정 반경 밖은 **NaN 으로 마스킹**해 외삽하지 않았다.

## 3. 방법과 설계 결정

**데이터**: `Si_Oxide_etch_89_points.csv`, `experiment_key` 결측 행 제외 →
웨이퍼 88장 × 좌표 89개 = **7,832행**. 반응변수는 `si_etch`.
좌표 파생 `r = √(X²+Y²)/1000` (mm), `θ = atan2(Y, X)`, 링 15개.

| 설계 결정 | 선택 | 이유 |
|---|---|---|
| 좌표별 기울기 모델 | `si_etch ~ C(lot_number) + wafer_number` | 4단계 pooled slope 와 **동일 형태** → 결과가 직접 비교 가능. lot 수준차가 기울기로 새는 것을 차단 |
| 반경 항 | `C(ring_id)` 비모수 | 프로파일이 보울형(비단조) → 2.3 참조 |
| 방위각 항 | 1차 조화항 `cos θ + sin θ` | 가장 해석 가능한 최소 모형. ΔR² 로 기여도 분리 |
| 다중검정 | BH FDR (89회) | 좌표마다 독립 검정이라 위양성 통제 필요 |
| 렌더링 | cubic + linear 대조 | 그림은 부드럽게, 신뢰도는 숫자로 |
| 외삽 | 볼록껍질 밖 NaN | r > 96.88 mm 는 **측정된 적이 없다** |
| 9점 대조 | 같은 89점 데이터를 9점 좌표로 절단 | 계측기 offset(3번 규칙)을 개입시키지 않고 **grid 효과만** 분리 |
| 코드 | 신규 파일, 리팩터링 없음 | 기존 3개 스크립트 무변경 → 재현성 재검증 불필요, A와 충돌 0 |

9점 좌표가 89점 좌표의 **진부분집합**임은 코드에서 `assert` 로 확인한다
(4단계 forensics 에서 이미 검증된 사실).

### 4.2 좌표별 drift 기울기 — drift 는 균일하지 않다

| 지표 | 값 |
|---|---|
| 89개 좌표 기울기 평균 | **−0.1188 µm/장** (4단계 89점 pooled −0.1189 와 일치) |
| 9점 좌표 9개 평균 | **−0.1053 µm/장** (4단계 89pt→9grid −0.1053 과 **정확히 일치**) |
| 범위 | −0.1948 ~ −0.0781 |
| 음의 기울기 | **89 / 89** |
| FDR < 0.05 | **89 / 89** |

**89개 좌표가 예외 없이 전부 감소하고, 전부 FDR 유의하다.** drift 는 웨이퍼 일부
영역의 현상이 아니라 전면적이다.

그러나 **속도는 균일하지 않다.**

- 중심(r=0) **−0.0944** → edge(r ≥ 95 mm, 좌표 20개) **−0.1613**
  = 가장자리가 **1.71배** 빠르게 drift
- 링 단위 최대는 r=95 mm 의 **−0.1651** → 중심 대비 **1.75배**
- 가장 빠른 좌표: r=95 mm, θ=143° 에서 **−0.1948 µm/장**
- 가장 느린 좌표: r=68.5 mm, θ=−34° 에서 −0.0781 µm/장

> ✅ **4단계가 남긴 추론이 확인되었다.** 89점이 9점보다 가파른 기울기를 보는 이유는
> 계측기 차이도 통계적 우연도 아니고, **9점이 못 보는 r > 76 mm 영역이 실제로 훨씬
> 빨리 drift 하기 때문**이다.

### 4.3 공간 패턴 3분해 — loc 성분의 정체

3단계의 `loc` 성분을 반경 / 방위각 / 국소로 한 겹 더 쪼갠 결과:

| 대상 면 | 반경 (C(ring_id)) | 방위각 (tilt ΔR²) | 국소·랜덤 | tilt 검정 |
|---|---|---|---|---|
| **평균 식각량 면** | **93.9%** | 5.4% | 0.8% | F=241.6, p=1.2e−32 |
| **drift 기울기 면** | **75.1%** | 9.4% | 15.5% | F=21.7, p=4.1e−08 |

**해석 1 — loc 성분은 노이즈가 아니라 결정론적 구조다.**
3단계에서 89점 산포의 98.25%(sd 등가 3.578 µm)를 차지하던 loc 성분은,
그 **93.9% 가 순수한 반경 함수**였다. sd 3.578 µm 중 **약 3.47 µm 가 반경 성분**이다.
"측정 위치 산포가 크다"는 3단계의 결론은 사실 **"웨이퍼가 반경 방향으로 일관되게
기울어 있다"** 는 뜻이었다. 이건 랜덤 변동이 아니므로 **원리적으로 공정 튜닝
(가스 분배, 압력, 포커스링 높이, 척 온도 프로파일)으로 개선 가능한 대상**이다.

**해석 2 — drift 면의 "국소 15.5%" 는 실제 구조가 아니다.**
좌표별 기울기는 회귀 추정값이라 자체 오차를 갖는다. 좌표별 표준오차의 제곱 평균은
`mean(se²) = 0.000144`, 기울기의 좌표 간 분산은 `0.000834` 이므로
**추정 잡음이 전체 분산의 17.3%** 를 차지한다. 이는 관측된 국소 성분 15.5% 와
거의 같다. 즉 **drift 맵은 반경 + tilt 만으로 사실상 전부 설명되며, 추가적인
국소 구조(핫스팟 등)는 없다.** 이는 drift 가 챔버 전역의 화학적 변화(벽 폴리머)
때문이라는 4단계 해석과 정합적이다.

### 4.4 방위각 비대칭 — 챔버에 고정되어 있다

  (θ=+101° 에서 47.79 µm 가 최소, θ=−79° 에서 51.58 µm 가 최대)

> 척 냉각 배관 비대칭)가 원인임을 강하게 시사한다.

쓰인 lot 이며, a 성분(−0.271)이 다른 lot(−0.01~−0.11)보다 크다. 다만 여전히
같은 사분면이라 결론에 영향은 없다.

### 4.5 9점 grid 커버리지 손실 — 실무 메시지

**같은 89점 데이터**를 9점 좌표로만 잘라 비교했다(계측기 차이 개입 없음, 순수 grid 효과):

| 지표 | 89점 전체 | 9점 grid | 9점의 과소평가 |
|---|---|---|---|
| 좌표 수 | 89 | 9 | — |
| 커버 최대 반경 | **96.88 mm** | **76.0 mm** | r > 76 mm 전부 미측정 |
| 평균 수준 | 43.67 µm | 41.58 µm | −2.09 µm |
| 웨이퍼 내 SD | **3.607 µm** | **1.060 µm** | **71% 과소평가** |
| 비균일도 (max−min)/mean | **26.85%** | **8.24%** | **69% 과소평가** |
| pooled drift 기울기 | −0.1188 | −0.1053 | **11% 과소평가** |

9점 grid 가 커버하는 반경은 r = 0, 53.74(×4), 76.0(×4) 뿐이다.
**최외곽 두 링(r = 95, 96.88 mm)은 좌표 20개 = 89점의 22%** 를 차지하는데,
이 영역의 평균이 49.85 µm(전체 평균 43.67 보다 6.2 µm 높음), drift 가 −0.161 µm/장
(1.71배)이다. **9점 grid 는 웨이퍼에서 가장 극단적이고 가장 빨리 변하는 22% 를
통째로 보지 못한다.**

> ⚠️ **6단계(Cp/Cpk) 로 넘어가는 경고**: 9점 계측 기반으로 공정능력을 산출하면
> 웨이퍼 내 산포를 **1/3 수준으로 축소 평가**하게 되어 Cpk 가 심각하게 낙관적으로
> 나온다. 6단계에서는 반드시 89점 기준과 병기해야 한다.

### 4.6 보간 불확실성

| 면 | max\|cubic − linear\| | 데이터 범위 대비 | 오버슈트 | 언더슈트 |
|---|---|---|---|---|
| 평균 면 | 1.617 µm | 14.0% (range 11.57) | 없음 (−0.015) | 0.211 µm |
| drift 면 | 0.0175 µm/장 | 15.0% (range 0.117) | 0.0009 | 0.0005 |

두 면 모두 국소적으로 **범위의 14~15%** 수준 차이가 날 수 있다. 차이는 좌표가
성긴 가장자리 부근에 집중된다. 따라서 **컨투어의 색은 정성적 참고용이고,
정량적 판단은 4.1~4.5 의 링 통계·좌표 통계로 해야 한다.** 그림에 실측 89점을
겹쳐 그린 이유가 이것이다.

IDW 보간점(`postox_thickness_nan` 결측) 영향: 보간점을 가진 좌표는 24개이고,
보간점을 제외했을 때 좌표 평균의 **최대 변화는 0.073 µm** 로 4.1 의 8 µm 반경 진폭에
비해 무시할 수준이다(4단계 결론과 동일).

## 7. 한계

1. **r > 96.88 mm 는 측정되지 않았다.** 웨이퍼 경계는 100 mm 이므로 최외곽 3 mm 는
   미지다. edge roll-up 은 보통 최외곽에서 더 급하므로, 실제 최대 식각량과 최대
   drift 는 **여기서 보고한 값보다 클 가능성이 높다.** 즉 4.5 의 "9점 과소평가"는
   보수적 하한이다.
2. **방위각을 1차 조화항까지만 분해했다.** 2차 성분(타원형 왜곡)은 분리하지 않았고
   국소 성분에 섞여 있다. 다만 4.3에서 drift 면의 국소 성분이 추정 잡음으로 거의
   설명되므로 실익은 크지 않을 것으로 본다.
3. **Rayleigh p 는 근사식**이다(n=10). R̄=0.998 이라 결론은 안전하지만 정확 검정은
   아니다.
4. **tilt 방향의 기준계가 불명확하다.** 좌표 X, Y 가 웨이퍼 노치 기준인지 챔버
   기준인지 계측 CSV 만으로는 알 수 없다. **웨이퍼가 항상 같은 방향으로 로딩된다는
   가정** 위에서 "챔버 고정 비대칭" 결론이 성립한다. → A에게 확인 요청(8번 참조)
5. **lot 7(6장), lot 10(4장)** 은 웨이퍼 수가 적어 tilt 추정 정밀도가 낮다.
   다만 두 lot 모두 다른 lot 과 같은 방향을 가리켜 결론을 흔들지 않는다.
6. **컨투어 색상은 정량 판단 근거가 아니다** (4.6). 숫자는 CSV 를 봐야 한다.
7. **인과가 아니라 구조**다. 반경 프로파일의 원인(가스 분배 / 포커스링 / 척 온도 중
   무엇인지)은 이 데이터만으로 분리할 수 없다. A의 `Process_data.nc` 파라미터와
   결합해야 좁힐 수 있다.
