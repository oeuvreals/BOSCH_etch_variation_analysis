## 2. 이론 배경

### 2.1 왜 σ 를 표본 표준편차가 아니라 MRbar/d2 로 잡는가

관리도의 σ 는 **군내(within-subgroup) 변동**만 담아야 한다. 개별값 차트(I chart)는
부분군 크기가 1이라 군내 변동을 직접 못 재므로, 연속한 두 점의 이동범위
MR_i = |x_i − x_{i−1}| 를 대용 부분군으로 쓴다. 크기 2 부분군의 범위 기댓값은
E[MR] = d2·σ, d2 = 1.128 이므로

```
sigma_hat = MRbar / 1.128
```

전체 표본 표준편차를 쓰면 **drift 자신이 σ 안으로 흡수되어 관리한계가 벌어지고**,
바로 그 drift 를 못 잡게 된다. 이 데이터가 정확히 그 상황이다:

| grid | σ_MR (단기) | sd_overall (장기) | 비 |
|---|---|---|---|
| 9점 | 0.2117 | 0.3463 | **1.64×** |
| 89점 | 0.2495 | 0.4019 | **1.61×** |

비가 1보다 크게 크다는 것 자체가 "군간에 계통 변동이 있다"는 증거다. 만약 표본
표준편차로 한계를 그었다면 한계폭이 60% 넓어져 이탈점은 더더욱 안 나왔을 것이다.

### 2.2 Western Electric 룰과 이 데이터에서의 적용 범위

3σ 이탈(룰1)만 보면 느린 변화를 놓치므로 보조 룰을 함께 쓴다.

| 룰 | 내용 | 감지 대상 |
|---|---|---|
| R1 | 1점이 3σ 밖 | 급격한 이상 |
| R2 | 연속 9점이 중심선 한쪽 | 평균 이동 |
| R3 | 연속 6점 단조 증가/감소 | **추세(drift)** |
| R4 | 연속 3점 중 2점이 같은 쪽 2σ 밖 | 중간 크기 이동 |

**설계 결정: R2/R3/R4 는 lot 내부에서만 판정한다.** 컨디셔닝이 챔버 상태를
리셋하므로 lot 경계를 가로지르는 연속열은 물리적으로 의미가 없다. 이걸 무시하고
전체 시계열에 룰을 걸면 lot 경계마다 가짜 신호가 쏟아진다. R1 만 전역 판정한다.

### 2.3 EWMA — 왜 필요하고 왜 lot 마다 리셋하는가

EWMA (지수가중이동평균)는 과거를 지수적으로 감쇠시켜 누적한다:

```
z_i = lam * x_i + (1 - lam) * z_{i-1},   lam = 0.2
관리한계: center +- L * sigma * sqrt( lam/(2-lam) * (1 - (1-lam)^(2i)) ),  L = 3
```

한 점의 잡음은 λ배로 축소되지만 **같은 방향의 작은 편차는 누적**되므로 1σ 내외의
느린 이동에 I 차트보다 훨씬 민감하다. drift 감지에 표준적으로 쓰이는 이유다.

한계식의 `(1 − (1−λ)^{2i})` 항 때문에 초기에는 한계가 좁고 점차 정상폭으로 벌어진다.
**lot 마다 z 를 중심선으로 리셋**하는 이유는 2.2 와 같다 — 컨디셔닝이 챔버를 되돌리므로
이전 lot 의 누적을 끌고 오면 안 된다. 리셋은 EWMA 를 불리하게 만드는 보수적 선택이다
(매 lot 초기의 좁은 한계 구간을 다시 지나야 하므로). 그럼에도 잡힌다는 것이 결과의 강도다.

### 2.4 Cp/Cpk vs Pp/Ppk — 단기와 장기

```
Cp  = (USL - LSL) / (6 * sigma_단기),     Cpk = min(USL - mu, mu - LSL) / (3 * sigma_단기)
Pp  = (USL - LSL) / (6 * sigma_장기),     Ppk = 동일 형태, sigma_장기
```

Cp 는 σ_MR(군내)을, Pp 는 전체 sd 를 쓴다. **Cp − Pp 격차 = drift 가 능력에서 뜯어가는
몫**이다. 이 데이터에서 1.6배 σ 차이는 곧 능력지수 1.6배 차이로 그대로 옮겨간다.

### 2.5 규격이 없을 때 — 역산(inverse capability)

공개 데이터셋에 소자 규격이 없다. 임의로 규격을 정하면 Cpk 는 그 임의값을 반영할
뿐 아무 정보가 없다. 대신 **질문을 뒤집는다**:

> "Cpk = 1.33 을 만족하려면 공차 반폭이 얼마여야 하는가?"

```
tol_halfwidth = Cpk_target * 3 * sigma
```

이건 데이터만으로 유일하게 결정되며, 나중에 실제 규격이 생기면 즉시 대조할 수 있다.

**주의 — 규격 중심을 관측 평균에 두면 Cp ≡ Cpk 가 된다.** 대칭 규격 + 중심 정렬은
치우침(off-center) 항을 0으로 만들기 때문이다. 즉 이 문서의 Cpk 는 **치우침을 뺀
산포만의 능력**이며, 실제 목표값이 관측 평균과 다르면 반드시 더 나빠진다. 낙관 상한이다.

### 2.6 웨이퍼 평균 능력 vs 전 측정점 능력

능력지수를 낼 때 "무엇 하나가 규격 안에 있어야 하는가"를 먼저 정해야 한다.

- **웨이퍼 평균 기준** — 공정을 lot-to-lot 으로 관리하는 관점. 웨이퍼 내 산포는 평균
  안에서 상쇄되어 사라진다.
- **전 측정점 기준** — 소자 관점. 웨이퍼 위 어느 다이에 있든 규격을 만족해야 하므로
  **모든 측정점이 규격 안**이어야 한다.

소자가 팔리는 단위는 다이지 웨이퍼 평균이 아니다. 따라서 **정직한 지표는 전 측정점**이다.
그런데 5단계에서 본 반경 프로파일(중심 대비 edge +19%) 때문에 웨이퍼 내 산포가
웨이퍼 간 산포를 압도하고, 두 기준의 격차가 극적으로 벌어진다. 이것이 6단계의 결론이다.

### 2.7 정규성 가정

Cp/Cpk 의 ppm 환산은 정규분포를 전제한다. 잔차 Shapiro-Wilk 검정 결과
9점 p = 0.0002, 89점 p = 0.0112 로 **정규성 기각**. 따라서 아래 ppm 수치는
**자릿수 감각용 근사**이며, 능력지수 자체(σ 대비 공차의 비)는 분포 가정 없이 유효하다.

## 3. 방법과 설계 결정

| 결정 | 선택 | 이유 |
|---|---|---|
| 규격 처리 | **역산 + 대표 공차(±3%, ±5%) 병기** | 규격을 발명하지 않으면서 숫자를 준다 (2.5) |
| 차트 구성 | **원자료 I + 잔차 I + EWMA 3종 병기** | "표준은 못 잡고 대안은 잡는다"를 같은 데이터로 대조 |
| 특수원인 | **표시 후 관리한계 산정에서 제외, 제외 전/후 병기** | 제외는 근거가 있을 때만. 영향도를 공개해 검증 가능하게 |
| 룰 판정 범위 | R1 전역, R2/R3/R4 는 lot 내부 | 컨디셔닝이 챔버를 리셋 (2.2) |
| σ 추정 | MRbar / 1.128 | drift 를 σ 에 흡수시키지 않기 위해 (2.1) |
| 균일도 차트 | `si_nu_pct` I-관리도 1패널 추가 | lot 6 w7 이 평균 차트로는 안 잡힘 (4.5) |
| 9점 / 89점 | 별도 산출 후 표로 병기 | 계측기가 달라 혼용 금지(CLAUDE.md #3). 격차 자체가 7단계 입력 |

### 3.1 특수원인 2건 — 제외 근거

데이터 준설이 아니라는 것을 보이기 위해 근거를 명시하고 제외 전/후 한계를 모두 싣는다.

| 웨이퍼 | 근거 | 출처 |
|---|---|---|
| lot 8 wafer 8 | `HeliumBPPressure` 하락 / `Gas1Flow` 상승 / `moriInnerCurrent` 하락, 런 길이 **+18%** (3835 vs ~3246 프레임) | **A** 가 `Process_data.nc` 에서 규명 |
| lot 6 wafer 7 | 89점 웨이퍼 내 비균일도 **25.94%** (나머지 87장 13.27 ± 0.28 → **z = +45**) | B, 이 단계에서 발견 |

> **z 값 정정.** 사전 탐색에서 이 점을 z = +9.1 로 적었는데, 그때 쓴 sd 1.379 는
> **이 이상점 자신이 부풀린 값**이었다. 이상점을 뺀 sd 는 0.279 이고 정직한

제외 영향도:

| grid | σ_MR 제외 전 | 제외 후 | 변화 |
|---|---|---|---|
| 9점 | 0.2111 | 0.2117 | +0.3% |
| 89점 | 0.2536 | 0.2495 | −1.6% |

**2% 미만.** 결론이 제외 여부에 의존하지 않는다.

## 4. 결과

### 4.1 Q1 — 표준 I-관리도는 drift 를 감지하지 못한다

**89점, 3σ 이탈점 0 / 88.** 관리한계 [42.927, 44.424], 중심 43.676.
차트만 보면 이 공정은 완벽하게 관리 상태다. 그런데 4단계에서 확인했듯 lot 안에서
웨이퍼는 −0.119 µm/장으로 단조 하강하고 있고, 10장이면 **−1.07 µm** 이동한다.
관리한계 폭이 ±0.75 µm 이므로 **drift 진폭이 한계폭과 맞먹는데도** 잡히지 않는다.

이유는 구조적이다. 각 lot 이 높은 값에서 시작해 낮은 값으로 끝나고 다음 lot 에서
리셋되므로, 전체 시계열은 톱니 모양이 되어 **평균 주위를 오갈 뿐 한계를 넘지 않는다**.
컨디셔닝이 이탈을 막아주는 셈이라, 표준 관리도로는 챔버가 계속 나빠지고 있다는
사실을 영원히 모른다.

9점에서는 3σ 이탈이 2건 나왔는데, **lot 3 wafer 10 과 lot 4 wafer 9** — 둘 다
lot 의 마지막 근처다. 이탈처럼 보이지만 실은 **drift 의 종착점**이고, 특수원인으로
오분류하면 엉뚱한 조사를 하게 된다.

### 4.2 Q2 — Western Electric 룰과 EWMA 는 잡는다

같은 원자료, 같은 한계, 룰만 추가:

| grid | R1 (3σ) | R3 (6연속 단조) | R4 (3중 2점 2σ) | 합계 |
|---|---|---|---|---|

| 89점 | **0** | **7** | **6** | **13** |

89점은 R1 이 0인데 R3/R4 로 13건이 잡힌다. **추세 룰(R3)이 이 공정의 주력 감지기**다.

EWMA (λ=0.2, L=3, lot 리셋):

| grid | 경보 lot | 최초 경보 웨이퍼 순번 (중앙값) |
|---|---|---|
| 9점 | 7 / 8 | **2번째** |
| 89점 | 8 / 10 | **3번째** |

**lot 의 3번째 웨이퍼에서 이미 경보가 뜬다.** 10장 중 3장 시점이므로, 실전이라면
남은 7장을 살릴 수 있다. 경보가 안 뜬 lot 7(5~6장만 존재) 과 lot 8·10(웨이퍼 수 부족
또는 특수원인 제외)은 표본이 짧아서지 성능 문제가 아니다.

### 4.3 잔차 관리도 — 계통 성분을 걷어내면 특수원인이 드러난다

`si_etch_mean ~ C(lot_number) + wafer_number` 로 lot 수준과 순번 drift 를 제거하면
(89점 R² = 0.810), 잔차 σ 는 0.1614 로 원자료 σ_MR 0.2495 의 **65%** 로 줄어든다.

| 웨이퍼 | 잔차 | 잔차 σ 대비 |
|---|---|---|
| lot 8 wafer 8 | +0.4265 | **+2.64σ** |
| lot 6 wafer 7 | −0.4456 | **−2.76σ** |

두 특수원인이 잔차 차트에서 나란히 상위로 올라온다. 원자료 차트에서는 각각 평범한
위치였다. **계통 성분을 모형으로 제거하는 것 자체가 감도 향상 수단**이라는 점이,
"관리도를 바꾸라"는 이 단계의 실무 권고의 근거다.

### 4.5 균일도 관리도 — 평균 차트가 놓치는 이상

`si_nu_pct` = (max−min)/mean 을 같은 I-관리도로 관리하면:

| grid | CL | σ_MR | UCL | 이탈 |
|---|---|---|---|---|
| 9점 | 4.196% | 0.035 | 4.301% | 2건 (lot 1 w6, w7) |
| 89점 | 13.274% | 0.170 | 13.784% | **5건** |

89점 이탈 5건 중 결정적인 것:

| 웨이퍼 | 비균일도 | σ_MR 대비 | **평균 잔차로는** |
|---|---|---|---|
| **lot 6 w7** | **25.94%** | **+74σ** | −2.76σ |
| lot 3 w2 | 14.60% | +7.8σ | −1.70σ |
| lot 8 w8 | 13.79% | +3.0σ | +2.64σ |

**lot 6 wafer 7 은 평균으로는 −2.76σ 에 그쳐 3σ 관리도에 걸리지 않지만, 균일도로는
자릿수가 다른 이상이다.** 웨이퍼 내 최대·최소 차이가 정상의 2배로 벌어진 상태 —
평균이 정상인 이유는 한쪽이 깊어진 만큼 반대쪽이 얕아져 상쇄됐기 때문이다.
**평균 차트만 운영하면 이런 웨이퍼가 그대로 통과한다.** 균일도 차트를 병행해야 하는
직접적 근거다.

### 4.6 Q4 — 결론: 주범은 drift 가 아니라 웨이퍼 내 불균일

| grid | 전 측정점 sd | 웨이퍼 평균 sd | 비 |
|---|---|---|---|
| 9점 | 1.022 µm | 0.346 µm | 3.0× |
| **89점** | **3.610 µm** | **0.402 µm** | **9.0×** |

같은 공차 ±3% 를 두 관점에 적용하면:

| 관점 | 89점 Cp | 불량 (근사) |
|---|---|---|
| 웨이퍼 평균 / 단기 | 1.75 | 0 ppm |
| 웨이퍼 평균 / 장기 | **1.09** | 1,116 ppm |
| **전 측정점 / 장기** | **0.12** | 716,680 ppm |

**Cp 1.09 → 0.12, 9배 격차.** 크기 비교로 정리하면:

```
drift 가 10장에 만드는 이동      -1.07 um
웨이퍼 한 장 안의 식각량 범위     약 12 um     <- 11배 크다
```

즉 **개선 1순위는 5단계의 반경 프로파일(edge roll-up), 2순위가 4단계의 drift** 다.
가상 시나리오로 확인하면:

| 시나리오 | 전 측정점 sd | Cp (±3%) |
|---|---|---|
| 현재 | 3.610 | 0.121 |
| **drift 를 완전히 제거** | 3.607 | **0.121** (변화 없음) |
| **반경 프로파일을 절반으로** | 1.848 | **0.236** (2배) |

drift 를 0으로 만들어도 전 측정점 Cp 는 소수점 셋째 자리까지 그대로다. 웨이퍼 간
성분(sd 0.402)이 웨이퍼 내 성분(sd 3.607) 앞에서 제곱합상 무시되기 때문이다.

이것이 3→4→5→6 단계를 관통하는 서사의 종착점이다. 3단계에서 loc 성분이 98.25% 라는
분산분해 결과를 얻었고, 5단계에서 그것이 결정론적 반경 구조임을 보였으며, 6단계에서
그 구조가 **공정능력이라는 실무 화폐 단위로 얼마인지**를 환산했다.

## 7. 한계

1. **규격이 없다.** 모든 Cp/Cpk 는 가정 공차에 대한 역산이며, 실제 소자 규격이
   나오면 재계산해야 한다.
2. **Cp ≡ Cpk.** 규격 중심을 관측 평균에 두었으므로 치우침이 0이다(2.5). 목표값이
   관측 평균과 다르면 실제 Cpk 는 더 낮다. **모든 수치는 낙관 상한.**
3. **정규성 기각** (Shapiro p = 0.0002 / 0.0112). ppm 환산은 자릿수 감각용.
4. **웨이퍼 97장, lot 10개.** lot 수준 추정의 자유도가 낮고, lot 7·10 은 웨이퍼가
   5~6장뿐이라 EWMA 성능 평가에서 사실상 제외됐다.
5. **특수원인 2건은 사후 식별.** 실시간 관리 상황이 아니라 전체 데이터를 보고
   골라낸 것이다. 다만 제외 영향도가 2% 미만이라 결론은 견고하다(3.1).
6. **관리한계가 이 데이터 자체에서 나왔다.** 이상적으로는 안정된 기준 기간(phase I)
   에서 한계를 정하고 이후를 감시(phase II)해야 한다. 여기서는 phase I 만 있는 셈.
7. **균일도 지표가 (max−min)/mean 이다.** 극값 2개에만 의존하므로 이상점에 민감하다.
   89점처럼 측정점이 많으면 sd 기반 지표가 더 안정적일 수 있다.
8. **EWMA 파라미터(λ=0.2, L=3)는 표준값을 그대로 썼다.** ARL 최적화를 하지 않았다.
