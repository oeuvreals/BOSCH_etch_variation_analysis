# BOSCH 식각 공정의 산포 구조 분해와 챔버 Drift 조기 감지

BOSCH DRIE(Deep Reactive Ion Etching) 공정 데이터를 분석해 식각 깊이 산포의
발생 원인을 계층별로 분해하고, 공정 센서 데이터만으로 챔버 상태 변화(drift)를
감지할 수 있는지 검증한다.

## 배경

동일 레시피로 웨이퍼 10장을 연속 처리했을 때, 뒤로 갈수록 식각 깊이가
감소하는 현상(-1.7%)이 관측된다. 챔버 내부 상태 변화에 의한 drift로 추정된다.

## 연구 질문

1. 산포는 어디서 오는가 — Lot 간 / 웨이퍼 간 / 웨이퍼 내 분산 분해
2. 얼마나 위험한가 — 관리도, Cp/Cpk 기반 품질 영향 평가
3. 실시간 감지 가능한가 — 공정 파라미터 기반 가상계측(VM) 모델

## 데이터

- 출처: Zenodo DOI 10.5281/zenodo.17122442 (CC-BY 4.0)
- 규모: 웨이퍼 약 97장, 10 lot
- 구성: OES(3648ch, 25Hz) / 공정 파라미터(31종, 5Hz) / 계측 결과(9점·89점)

원본 데이터는 저장소에 포함하지 않는다. 취득 방법은 docs/DATA.md 참조.
